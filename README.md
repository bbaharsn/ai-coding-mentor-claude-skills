# ai-coding-mentor-claude-skills
A step-by-step coding mentor skill for Claude.

## Skill'ler

| Skill | Ne işe yarar |
|---|---|
| [papercraft-add-property](skills/papercraft-add-property/SKILL.md) | PaperCraft editöründe bir canvas elemanına yeni düzenlenebilir özellik ekleme akışı (model, katalog, Özellikler sayfası, test, simülatör). |

## Kurulum

Bir skill'i tüm projelerde kullanmak için `~/.claude/skills/` altına kopyala:

```bash
git clone https://github.com/bbaharsn/ai-coding-mentor-claude-skills.git
cp -R ai-coding-mentor-claude-skills/skills/papercraft-add-property ~/.claude/skills/
```

Yeni bir Claude Code oturumu açınca skill listede görünür.
